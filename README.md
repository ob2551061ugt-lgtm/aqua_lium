# 🐟 ピクセル水族館

ブラウザで遊べるドット絵の水族館運営ゲームです。GitHub Pagesにそのまま置いて公開できます（サーバー不要・ビルド不要）。

## 遊べること
- **6種類のブース**：熱帯淡水・渓流（日本の川魚）・海水・クラゲ・汽水・深海。ランクが上がると順番に解放されます
- **151種**：ネオンテトラから錦鯉、ジンベエザメ、リュウグウノツカイ、オオサンショウウオまで。クラゲブースにはミズクラゲ・カツオノエボシ・カブトクラゲ・ユウレイクラゲなど**クラゲ24種**
- **繁殖**：同じ種類の大人のオス♂とメス♀が同じ水槽にいて、空きがあると赤ちゃんが生まれます
- **色違い**：赤ちゃんは1/64で色違い（親が色違いだと確率アップ）。ショップにもまれに入荷します
- **図鑑**：発見・飼育・色違いの3段階で記録。登録数に応じて魅力ボーナスがつきます
- **飾りつけ**：岩・水草・サンゴ・海底城・鳥居・沈没船など20種。水槽をクリックして好きな場所に置けます
- **フレンド**：フレンドコード（名札）、見学リンク、来訪スタンプ（来訪者ノートに記録）、魚のトレード
- **放置収入**：ゲームを閉じている間も最大8時間ぶんの入館料が入ります

## GitHub Pagesで公開する手順
1. GitHubで新しいリポジトリを作る（例：`pixel-aquarium`）
2. このフォルダの中身（`index.html`・`css/`・`js/`・`.nojekyll`）をそのままアップロード
   - ブラウザなら「Add file → Upload files」にドラッグ＆ドロップでOK
3. リポジトリの **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/pixel-aquarium/` で遊べます

ローカルで試すときは `index.html` をダブルクリックするだけで動きます。

## フレンド機能のしくみ
GitHub Pagesは静的サイトなのでサーバーがありません。そのため、データを**コード（リンク）に詰めて送り合う**方式にしています。

| 機能 | 使い方 |
|---|---|
| 見学 | フレンド画面で「見学リンクを作る」→ 友達に送る → 友達が開くとあなたの水族館が表示される |
| 来訪スタンプ | 見学した人が「スタンプを作る」→ 館長に送り返す → 来訪者ノートに名前とメッセージが残る（1人1日1回ボーナス） |
| トレード | 水槽の魚リストで「トレード」→ リンクを相手に送る。相手のフレンドコードを指定するとその人だけが受け取れる |

コードには改ざん検出用のチェックサムが付いていますが、ブラウザだけで動くゲームなので完全な不正防止はできません（友達同士で楽しむ前提です）。
「フレンドコードを入力するだけで相手の水族館が見られる」ようにしたい場合は、Firebase などの無料のバックエンドを追加すると実現できます。

## ファイル構成
```
index.html      画面の骨組み
css/style.css   見た目
js/data.js      魚・飾り・ブースのデータ（魚を増やすならここに1行追加）
js/sprites.js   ドット絵の自動生成（形・模様・色違いをプログラムで描画）
js/codec.js     見学・スタンプ・トレード・バックアップのコード変換
js/game.js      ゲーム本体
```

### 魚を追加するには
`js/data.js` の `SPECIES` に1行足すだけです。
```js
F('id', '名前', '水質', レア度1-5, '形', '体の色,腹の色,ヒレの色,尾の色', [模様], {形の調整}, '図鑑の説明'),
```
- 水質：`fresh` `river` `sea` `jelly` `brackish` `deep`
- 形：`std` `small` `tiny` `slim` `tall` `angel` `round` `ranchu` `puffer` `box` `long` `eel` `betta` `guppy` `cat` `goby` `shark` `big` `tuna` / 特殊：`seahorse` `crab` `shrimp` `jelly`（傘の形 `dome` `flat` `bullet` `cube` `comb` `float` `disc`、触手・口腕の数や長さを指定）`turtle` `ray` `isopod` `squid` `dumbo`
- 模様の例：`['bands', '#fff', '#000', 3, 0.06]`（縦帯）、`['spots', '#000', 0.2, 種]`（斑点）、`['hstripe', '#0ff', -0.5, 0, 0, 1]`（横帯）、`['blob', '#f00', 3, 0.5, 種]`（錦鯉のようなまだら）

※ 一度公開したあとに `SPECIES` の並び順を変えると、古い見学コードの魚がずれます。新しい魚は**末尾に追加**してください。
